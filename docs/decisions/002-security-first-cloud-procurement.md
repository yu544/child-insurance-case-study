# ADR 002: 安全优先的云资源采购

## 背景

客户明确关注儿童资料安全。系统会处理姓名、身份证号、人脸资料照、监护人手机号和保险订单状态。

## 决定

采购独立云服务器、云数据库、对象存储、HTTPS 证书和主机安全能力，而不是把全部能力堆在单台服务器上。

## 理由

- 后端统一保管第三方密钥，前端不直连云 API 或保险平台
- 数据库可关闭公网入口，仅允许服务器内网访问
- 儿童照片放私有对象存储，避免静态链接长期传播
- HTTPS 和备案是正式上线、小程序审核和传输安全的基础
- 主机安全和登录加固用于应对公网扫描与弱口令风险

## 代价

- 采购和配置成本更高
- 需要额外维护备份、权限和证书续期
- 需要向客户解释每项资源和数据安全之间的关系
