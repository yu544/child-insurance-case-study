# 开源边界说明

这是一个付费客户项目的作品集版本，不是生产系统源码。

## 公开内容

- 脱敏后的产品背景与系统架构
- 数据安全设计与云资源采购依据
- 可复用的通用代码样例
- 不依赖外部服务的测试
- 脱敏界面截图

## 不公开内容

- 真实客户名称、合同、报价单、客户联系人
- 生产仓库、提交历史、部署脚本和服务器配置
- 服务器 IP、域名、数据库地址、小程序 AppID
- 第三方保险平台真实接口文档、字段、签名规则和密钥
- 真实儿童姓名、身份证号、人脸照片、监护人手机号、保单号
- 渗透测试的攻击细节

## 为什么这样处理

开源展示的目标是证明项目能力，而不是复制生产系统。对于处理未成年人数据的商业项目，保护客户和用户隐私本身就是产品能力的一部分。
