# ADR 001: 小程序原生壳 + H5 主业务

## 背景

项目需要微信登录、拍照能力和小程序入口，同时上线前业务页面会频繁调整。如果全部使用小程序原生页面，任何前台流程、投保文案和老板看板调整都可能触发重新审核。

## 决定

小程序原生侧只承担登录、拍照和 web-view 容器，核心业务页面由 H5 承载。

## 理由

- 保留微信生态能力
- 降低业务页面迭代对微信审核的依赖
- 方便在门店 UAT 期间快速修改异常提示和流程细节

## 代价

- 需要设计登录态交接
- 需要处理 web-view 域名备案和 HTTPS 配置
- 小程序壳与 H5 的视觉体验需要额外对齐
