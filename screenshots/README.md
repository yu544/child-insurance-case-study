1. 家长扫码建档页

## 截图前必须处理

- 儿童姓名使用明显假名，例如“张小明”“李小雨”
- 手机号显示为 `138****1234`
- 身份证显示为 `1101 **** **** 0000`
- 保单号显示为 `POL-2026-0001`
- 不展示真实生产域名、服务器 IP、小程序 AppID
- 不展示客户营业执照、统一社会信用代码、真实门店主体
- 不展示真实儿童照片或可识别的人脸图像
- 不放真实报价单、合同、客户经理姓名
